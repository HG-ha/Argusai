# ArgusAI v0.1.0

ArgusAI v0.1.0 是项目公开开源后的首个正式版本。

ArgusAI 是由[达瓦科技](https://dawahezhi.com/)开源的 Agent 原生安全工作台。它把 Agent、浏览器、Web 扫描、代理流量、逆向分析、证据与自动化任务放进同一个本地工作区。使用者可以直接描述目标、提供材料和授权范围，由 Agent 组织工具、Skills、计划与证据，持续推进分析、验证、记录和交付。

> 把目标交给 Agent，让它在 ArgusAI 中完成工作。

## Agent 是工作台的默认入口

完整对话和悬浮球都连接同一套 Agent 能力。Agent 可以结合当前页面、正在查看的任务或逆向作业继续工作；使用者也可以在功能页查看进度、核对证据或随时介入。

本版本的 Agent 运行时支持：

- 多模型、多端点和故障回退，按会话独立保存模型选择；
- 工具与 Markdown Skills 两层能力，按任务逐步发现并加载所需工具；
- 计划、待办、检查点、上下文压缩、知识和大结果归档；
- 流式响应、结构化工具步骤、证据引用、取消和进展检查；
- 持久小队与子 Agent，按角色、模型和工具范围协作；
- 每个对话独立的自动审批设置，高风险工具仍遵守强制二次确认；
- Agent 对话、悬浮球、CLI、多种通信渠道和本地 ACP Agent 入口。

运行时没有固定的模型或工具轮次上限，默认单轮紧急时限为 7 天。一次用户任务可以连续执行数十小时，持续调用模型与工具，并在上下文增长时压缩和归档。实际执行时长取决于模型额度、网络、外部工具、主机资源以及任务授权范围。

## 持续执行、自动巡检与主动发现

ArgusAI 内置四类自动化触发器：

- 固定间隔：适合周期巡检、进度查询和新增流量复核；
- Cron：适合每日资产复查、每周暴露面检查和定时简报；
- 签名 Webhook：接收构建、告警或其他系统事件；
- 文件变化：分析新日志、新报告或样本目录中的变化。

自动化任务可以每次新建对话、使用任务专属对话，或继续指定的现有对话。`max_runs=0` 允许任务不按固定次数结束。Agent 会在每轮读取计划与检查点，完成下一步，保存结果并等待后续触发，从而支持长期调查、基线对比、自动巡检和近乎无限的分段续跑。

通知可以聚焦新增风险、执行失败和需要人工处理的节点。无变化的巡检可以保持安静，减少重复信息。

## Web 安全审计

ArgusAI 将批量检查、浏览器观察、原始请求和证据统一到任务中。本版本覆盖的工作方向包括：

- 资产与技术栈识别、页面和接口发现；
- HTTP 安全头、TLS、Cookie、跨域和缓存配置检查；
- 敏感信息、密钥、调试信息、源码与目录暴露检查；
- 身份认证、会话、访问控制、文件上传与业务流程检查；
- 注入、XSS、SSRF、路径处理和 HTTP 协议类风险探测；
- 浏览器 DOM、脚本、网络活动、截图和交互过程观察；
- 原始请求保存、重放、差异比较和报告证据整理。

内置探测默认采用非破坏方式，并在每次请求前遵守目标 scope。生产系统中的验证范围、账号和允许动作仍由使用者明确提供。

## 代理流量与协议分析

被动 MITM 代理支持 HTTP/1.1、HTTP/2 和 WebSocket 流量。工作台可以：

- 查看请求、响应、连接和 WebSocket 消息；
- 使用规则驱动的被动分析；
- 设置断点，并在明确允许时改写或阻断流量；
- 导入、导出 HAR，并接入已有 Burp 日志；
- 将流量记录交给 Agent 归类、复核、重放和形成证据。

## JS、WASM、移动端与二进制逆向

统一 ReverseJob 将样本、运行状态、工具输出和证据关联起来。

JS 与 WASM 工作流包括静态分析、格式化、依赖与接口提取、Source Map、Webpack、反混淆、JSVMP 辅助分析、Hook、签名算法定位和加密流程复现。浏览器动态观察可以与代理流量、HAR 和已有任务材料共同使用。

移动端工作流可以接入 APK、IPA、JADX、APKTool、ADB、签名工具、Frida 和 Objection。二进制工作流可以接入 PE、ELF、Ghidra、capa、YARA 和宿主 Frida。外部程序按需安装，ArgusAI 负责发现、编排、保存输出并交给 Agent 继续分析。

## 网络、云与专项安全工作流

工作台可组织 DNS、WHOIS、端口与服务发现、带外验证，以及 Nuclei、ffuf、sqlmap 等外部工具。所有主动操作都应在明确授权和 scope 内进行。

ArgusAI 也提供云配置、IaC、Kubernetes、SBOM、离线 PCAP、目录服务、无线网络、固件和 IoT 等专项工作的集成入口。具体能力取决于本机安装的工具、使用者提供的数据和目标环境；这些入口用于把专项材料和外部分析结果纳入同一 Agent 工作流。

## 证据、知识与报告

Case、Artifact、Evidence、发现和会话可以相互关联。Agent 能将长输出写入文件或知识库，并在后续轮次和自动化任务中继续使用。

扫描结果支持 HTML、Markdown 和 JSON 报告。证据引用、原始请求、截图、逆向产物、任务日志和整改复测记录可以保留在同一数据目录，便于复查和交付。

## 企业安全应用方向

### 内网安全防护

在授权的 IP、CIDR、主机和 SSH 范围内发现资产与服务暴露，整理端口、防火墙摘要、失败登录和关键服务版本，持续对比基线并输出变化与加固建议。

### 应用安全防护

接入预发布环境、测试身份、接口材料、HAR、JS 和业务日志，联动 Web 检查、浏览器和代理分析配置、认证、访问控制与异常请求，保存复现材料并安排整改复测。

### 攻击溯源

在指定时间窗口内整理业务日志、主机审计、代理流量以及使用者提供的 WAF、EDR、SIEM 告警，关联时间、账号、IP、进程和请求标识，形成事件时间线、证据关系、置信度和证据缺口。攻击者身份归因仍以组织掌握的证据为准。

### 持续攻防

围绕已授权资产和约定靶场，串联暴露面发现、单独授权的受控验证、检测证据复核、修复和复测。长时单轮执行、事件触发和周期任务可以持续推进演练，并沉淀检测差距、复盘材料和可复用的 Skills。

## 开放扩展与集成

开发者可以通过 Python Check、Agent Tool 和 Markdown Skill 扩展工作台，也可以连接 MCP、本地 ACP Agent 与桌面自动化。

通信渠道支持按需接入 Telegram、Discord、Slack、飞书、钉钉、企业微信、微信和通用 Webhook。外部渠道的可用性取决于相应平台配置和网络环境。

## 首次使用

1. 安装或解压对应平台的发行包。
2. 启动 ArgusAI，在设置中配置自己的 AI 服务端点、模型和数据目录。
3. 按需检查浏览器、代理证书和外部安全工具路径。
4. 打开 Agent 对话或点击悬浮球，描述目标、材料、授权范围和禁止动作。
5. 在功能页观察过程、核对证据，并在确认节点决定是否继续。

Windows 桌面依赖 Microsoft Edge WebView2 Runtime。Windows ARM64 还需要另行安装原生 Microsoft .NET Desktop Runtime，缺失时桌面界面无法初始化。Linux 桌面需要 GTK 与 WebKitGTK。macOS 桌面自动化需要使用者授予相应系统权限。

模型服务、浏览器运行时、大型外部扫描器和逆向工具不会全部内置进发行包。源码归档也不重复收录所有外部依赖的源码；发行包中的来源说明提供相应获取方式。这样可以控制下载体积，并由使用者决定具体版本与授权方式。

## 开源协议与使用边界

ArgusAI 以 `GPL-3.0-only` 发布。第三方组件保留各自许可证与声明，发行包中的 `licenses` 目录包含对应材料和源码获取说明。

本项目用于合法授权的安全防护、审计、研究和测试。使用者需要确认目标范围、数据处理要求和操作权限。高风险动作不会因开启自动审批而绕过强制确认。
