# ArgusAI v0.1.1

ArgusAI v0.1.1 是桌面交互与 AI 端点诊断的维护版本。它修复了 Windows 自定义标题栏会把按钮操作误判为窗口拖动的问题，也让端点探测更快、更接近用户当前填写的配置。

## 本次修复

### Windows 自定义标题栏

- 语言切换、帮助、最小化、最大化、还原和关闭按钮已从窗口拖拽区域中分离，点击不再触发原生拖动。
- 标题文字与空白区域仍可拖动窗口，双击可切换最大化和还原。
- Windows Snap、任务栏还原等系统操作会同步窗口状态，下一次点击最大化按钮时不会出现状态相反的问题。
- 为这些 DOM 和桥接约束增加了回归测试。

### AI 端点探测

- 探测会使用设置页中尚未保存的 Base URL、模型、协议、自定义请求头和请求体。
- 从脱敏端点列表发起探测时，会按端点索引恢复本地保存的 API Key；密钥不会写入探测结果。
- 单次探测的输出上限收敛到 16 tokens，超时上限收敛到 30 秒，失效端点不会让设置页等待数分钟。
- 模型列表探测会携带当前模型，并复用同一套端点凭据解析逻辑。
- 连接关闭异常不再覆盖已经得到的探测结果。

## ArgusAI 能做什么

ArgusAI 是由[达瓦科技](https://dawahezhi.com/)开源的 Agent 原生安全工作台。Agent 能读取当前工作区状态，操作扫描、代理、浏览器、逆向、知识库、任务和报告能力，并把过程证据保存在本地工作区。

一次对话可以连续运行数十小时。运行时支持多端点回退、Skills、检查点、上下文压缩、持久小队与子 Agent。固定间隔、Cron、签名 Webhook 和文件变化四类触发器可以驱动自动巡检、主动发现、基线对比和分段续跑。`max_runs=0` 的任务可长期运行，实际持续时间仍取决于模型额度、网络、主机资源和授权范围。

常见用途包括：

- 内网安全防护、应用安全防护和持续攻防；
- Web 安全审计、被动流量分析和攻击溯源；
- JS/WASM 逆向、加密参数复现和接口证据整理；
- 周期巡检、告警复核、变更检查和安全报告交付。

所有测试都应在明确授权范围内进行。高风险工具仍要求二次确认；自动审批不会绕过强制确认策略。
