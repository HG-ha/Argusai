# ArgusAI v0.1.15

- 每个通讯渠道配置新增独立的“流式回复”开关，默认开启，可在渠道详情直接切换或在编辑窗口设置；关闭后完整发送回复，保留 Agent 主动分多条消息的能力。
- 修复飞书长任务过程中，进展文本未及时推送、卡片更新顺序错乱及流式失败后延迟回退的问题；缺少原生流式卡片权限时使用普通卡片更新。
- 修复通讯渠道投递记录在多条消息时间戳相同时显示顺序颠倒的问题。
- 新增统一的 macOS 权限页，可从设置或 Agent 对话顶部打开，查看权限状态、用途说明并跳转对应系统设置。
- 优化桌面权限提醒：可随时关闭，重启后保留关闭选择；历史工具卡片中的权限说明默认折叠，不影响普通对话。
- 语音录制改为按需申请麦克风权限，支持等待授权、取消和拒绝后的恢复；仅本地应用页面可使用已授予的麦克风权限。
- macOS 桌面通知改用 ArgusAI 自身身份，支持权限申请与状态查询；后台任务不会主动弹出授权框。
- 补充本地网络、自动化、文件与文件夹、完全磁盘访问的按需授权引导，以及安装包中的用途声明和签名权限。
- 安装版提供可关闭的应用图标拖拽卡片，方便添加桌面操作权限；权限页面适配深浅色、窄窗口及多语言。
