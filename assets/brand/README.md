# Brand assets

The desktop UI and release packager use the files in this directory:

| File | Use |
| --- | --- |
| `readme-banner.svg` | Static README illustration connecting Agent, browser, proxy, reverse and evidence workflows |
| `argusai-icon-Transparency.png` | Transparent icon used by the UI and Linux builds; source for installer artwork |
| `argusai-icon-Transparency.ico` | Windows executable and NSIS icon |
| `argusai-icon.icns` | macOS application and DMG icon |
| `argusai-icon.png`, `logo.png` | Additional raster brand assets |

Build from the repository root with `uv run --group build python build.py`. The script selects the platform icon automatically. Use `--icon path/to/icon` to override the executable icon; the NSIS installer keeps the project brand icon.

After changing the transparent PNG, regenerate the macOS icon on macOS:

```sh
bash scripts/create_icns_macos.sh
```

Installer artwork is generated by `scripts/windows/make_nsis_art.py` and `scripts/macos/make_dmg_art.py`; `build.py` invokes the relevant helper when creating NSIS or DMG packages.
