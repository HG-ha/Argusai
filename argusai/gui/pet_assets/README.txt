ArgusAI Chinese dragon companion.
Character animation: FilmOS / Seedance 2.5 and MiniMax H3, generated for this project.
Seven activity states, drag intro and release, plus four independent directional drag loops.
384 x 384 RGBA animated WebP; 60 FPS motion-interpolated from 24 FPS video.
Green-screen keyed, fixed per-clip scale, shared body palette and baseline.
Malformed transition intervals are excluded. Directional loops keep one shared fixed scale.
Loop closure uses the selected real-motion interval followed by its reverse.
Production sources and validation receipts are maintained outside the package.
No API credentials or personal application settings are packaged.
