从一句任务开始。

对话、工具、文件和执行记录，在同一个工作区。

它能调动的，
是整个工作台。

Agent 能读取当前任务状态，操作浏览器、分析代理请求、建立逆向作业，按需要调用工具和技能。你可以随时打开功能页，看它查到了什么、正在做什么。

展开 Agent 的工作过程 ↗

浏览器与流量

打开页面、观察交互，捕获请求，沿着真实流量分析接口与权限。

↗

代码与沙盒

编写并运行脚本，检查输出，把报告和中间产物留在会话工作区。

↗

样本与逆向

从 JS、WASM 到应用与二进制样本，组织分析工具，复现并验证结论。

↗

协作与续跑

拆分子任务、组织小队、保存检查点，由计划和事件接续后面的工作。

↗

离开电脑，
也能把任务交给它。

在 QQ、飞书、Telegram、Slack 等渠道发送任务与文件，接收回复和产物。ArgusAI 在你的电脑或服务器上继续运行。

了解通讯接入 ↗

模型、工具和数据，按你的环境来。

支持多端点路由和本地大模型。准备好模型与工具依赖后，可以部署在内网或离线环境，处理敏感业务。底层运行时也可用于文件处理、代码执行和通用 Agent 任务。
